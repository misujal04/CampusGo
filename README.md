# RideSync 🚗

### College Student Ride-Sharing Platform

RideSync is a college-focused ride-sharing platform designed to connect students travelling on similar routes at compatible times. The platform helps students coordinate shared rides, manage bookings, and share travel expenses conveniently.

The project aims to make daily college commuting more affordable, convenient, and efficient by making better use of available seats in private vehicles.

## 🎯 Project Objectives

- Connect college students travelling on similar routes.
- Match students based on pickup locations, destinations, and travel schedules.
- Support recurring rides for regular college schedules.
- Enable students to create, search, join, and manage rides.
- Calculate and share travel expenses among passengers.
- Provide student verification, ratings, and feedback to improve trust.
- Reduce individual commuting costs and unnecessary vehicle usage.

## ✨ Key Features

The planned system includes the following modules:

1. **User Registration and Student Verification** — Student registration, login, profile management, and identity verification.
2. **My Rides Management** — Create rides, manage available seats, handle ride requests, and view ride history.
3. **Ride Search and Smart Matching** — Find suitable rides based on routes, timings, and seat availability.
4. **Expense Sharing and Settlement** — Calculate shared travel expenses and track settlements.
5. **Feedback and Rating Management** — Rate drivers and passengers and submit feedback after rides.
6. **Admin Management** — Manage student accounts, verification requests, complaints, and reported activities.
7. **Notification and Alert Management** — Notify students about ride requests, confirmations, cancellations, upcoming rides, and payment updates.

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Web page structure |
| CSS3 | Styling and user interface |
| JavaScript | Frontend interactivity |
| Python | Backend programming |
| Django | Web application framework |
| MySQL | Database management |
| Git & GitHub | Version control and collaboration |
| Visual Studio Code | Development environment |

## ⚙️ Expected Workflow

1. A student registers and verifies their college identity.
2. The student creates a ride or searches for an available ride.
3. RideSync identifies compatible rides based on routes and travel times.
4. Students send, accept, or reject ride requests.
5. Available seats and shared travel expenses are managed.
6. After completing a ride, students can submit ratings and reviews.
